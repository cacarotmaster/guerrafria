# 🕵️ La Guerra Fría: Misión Secreta

Estrategia de **gamificación** para el área de **Ciencias Sociales** (grados 8°–11°) sobre la **Guerra Fría (1945–1991)**.

El estudiante asume el rol de un agente secreto y debe tomar decisiones históricas clave para **evitar la Tercera Guerra Mundial**, desarrollando conciencia sobre el mundo bipolar y la construcción de la paz.

## 🎮 Cómo funciona

1. **Elige tu rol**: Espía 🕵️, Diplomático 🤝 o Científico 🔬 — cada uno tiene una habilidad distinta.
2. **Supera 4 misiones históricas**:
   - 🛫 Bloqueo de Berlín (1948–1949)
   - 🚀 La Carrera Espacial (1957–1969)
   - ☢️ Crisis de los Misiles (1962)
   - 🧱 Caída del Muro de Berlín (1989)
3. **Toma decisiones** que cambian tu **Poder Geopolítico**. Decisiones de alto riesgo cuestan **vidas** (❤️ 3 en total).
4. Al final obtienes un **resultado** según tu desempeño, con **insignias** y tu **mejor puntaje guardado**.

## 🛠️ Tecnología

- [Vite](https://vitejs.dev/) + [React](https://reactjs.org/) + [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/) + [shadcn/ui](https://ui.shadcn.com/)
- Despliegue automático a **GitHub Pages** vía GitHub Actions

## 🚀 Desarrollo local

```sh
npm install
npm run dev
```

## 🌐 Compilar

```sh
npm run build
# genera la carpeta dist/ (base configurada para GitHub Pages: /guerrafria/)
```
